# Crear una adaptación privada para un centro

Esta carpeta contiene una plantilla pública y vacía. Para utilizarla en un centro:

1. crea una copia separada del repositorio o descarga únicamente la plantilla;
2. guarda la adaptación en un repositorio privado o en el entorno institucional autorizado;
3. configura solo las enseñanzas, programas, responsables funcionales y fechas internas que necesite el centro;
4. mantén referencias a las fuentes oficiales y registra qué elementos has modificado;
5. no devuelvas al repositorio público la plantilla cumplimentada.

## Información que no debe publicarse

No incorpores al repositorio público:

- nombres del profesorado, alumnado o familias;
- credenciales, claves o enlaces privados;
- actas, informes, incidencias o evidencias reales;
- decisiones reservadas o documentos internos;
- datos personales o cualquier información confidencial.

## Validez

La adaptación sigue siendo una herramienta de apoyo. Todas las fechas, datos e instrucciones deben contrastarse con las Instrucciones oficiales de inicio de curso, la normativa vigente y las modificaciones posteriores aplicables.
